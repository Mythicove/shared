# Contributing

Canonical guide on the docs site: [English](https://mythicove.github.io/docs/en/community/contributing/) · [中文](https://mythicove.github.io/docs/community/contributing/)

This repository is a shared Go module consumed by `mythic-mirror` / `mythic-hoard`: changes to interfaces or domain types are cross-repo changes — start with an issue or an ADR in `docs`. Keep zero third-party dependencies; CI runs `govulncheck`.

Security vulnerabilities: do not open a public issue; use the private reporting flow in [SECURITY.md](./SECURITY.md).
